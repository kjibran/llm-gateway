# LLM Gateway

An OpenAI-compatible gateway that routes chat requests across free LLM providers (Groq, Gemini, OpenRouter) and falls back automatically when one is rate-limited, overloaded, or down.

Work in progress. Live demo, architecture diagram, and design notes coming soon.
